# dbiForest 

Implementation of the density based Isolation Forest (dbiForest) as described in 
"Détection d’anomalies dans les données d’essais de moteurs
aéronautiques : développement de nouvelles méthodes fondées
sur les forêts d’isolation", "Anomaly Detection in Aeronautical Engine Test Data: 
Development of Novel Methods Based on Isolation Forests" 
Nathan LEVEQUE, Emmanuel FRENOD, Jérome LACAILLE, Audrey POTERIE, François SEPTIER

This repositery contains the reference implementation of the dbiForest and online dbiForest as develloped during 
thesis work. It also contains a notebook to illustrate the use of the models on simple simulated dataset

## Installation 

Clone the repositery 

git clone https://github.com/nathleve/dbiForest
cd dbiForest

install dependencies 
pip install -r requirements.txt
